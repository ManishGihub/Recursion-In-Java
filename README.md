# Recursion in Java

A beginner-friendly Java repository to understand the fundamentals of **Recursion** through simple and easy-to-follow programs.

This repository contains basic recursive problems implemented in Java, covering concepts like:

* Base Case
* Recursive Calls
* Stack Height
* Backtracking Flow
* Time Complexity Basics

---

## 📚 Programs Included

### 1. Factorial of a Number

**File:** `Factorial.java`

Calculates the factorial of a number using recursion.

#### Example

```java
Input: 5
Output: 120
```

#### Concept Used

```text
n! = n × (n-1)!
```

---

### 2. Fibonacci Series

**File:** `Fibonacci.java`

Prints the Fibonacci sequence using recursive function calls.

#### Example

```java
Output:
0 1 1 2 3 5 8
```

#### Concept Used

```text
F(n) = F(n-1) + F(n-2)
```

---

### 3. Print Numbers from 5 to 1

**File:** `FiveToOne.java`

Uses recursion to print numbers in decreasing order.

#### Output

```java
5
4
3
2
1
```

---

### 4. Print Numbers from 1 to 5

**File:** `OneToFive.java`

Uses recursion to print numbers in increasing order.

#### Output

```java
1
2
3
4
5
```

---

### 5. Sum of First N Natural Numbers

**File:** `SumOfN.java`

Finds the sum of first `N` natural numbers recursively.

#### Example

```java
Input: 5
Output: 15
```

Also demonstrates how recursion unfolds during backtracking.

---

### 6. Calculate xⁿ using Recursion (Stack Height = n)

**File:** `XPowNStackHeightn.java`

Computes power recursively with linear recursion depth.

#### Example

```java
2^5 = 32
```

#### Time Complexity

```text
O(n)
```

---

### 7. Calculate xⁿ using Optimized Recursion (Log n)

**File:** `XPowNStackHeightlogn.java`

Efficient recursive solution using **Divide and Conquer** approach.

#### Example

```java
2^5 = 32
```

#### Time Complexity

```text
O(log n)
```
